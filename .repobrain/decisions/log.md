# Architectural Decision Log

This log records major design decisions and changes in the project timeline.

| Date | Decision Summary | Impact |
| :--- | :--- | :--- |
| **2026-07-28** | Initialized AI Knowledge Base (`.ai/`) & set AI Bootstrap order. | Grounded context for AI agents without initial codebase reverse engineering. |
| **2026-07-28** | Adopted Payload CMS + Custom FFmpeg Video Pipeline (ADR-0001). | Unified editorial CMS with decoupled HLS video processing. |
| **2026-07-28** | Setup RepoBrain workspace knowledge hub (`.repobrain/`). | Cross-IDE grounded repository context via RepoBrain CLI & `rb-ask`. |
| **2026-07-28** | Eliminated Caddy reverse proxy container in favor of direct Cloudflare Tunnel container routing. | Simplified stack footprint for Oracle VPS deployment (`cmm.alamiaai.com` & `cmmadmin.alamiaai.com`). |
| **2026-07-28** | Completed Sprint 0 Project Foundation scaffolding. | Portainer stack (`docker-compose.yml`), `cms/`, `web/`, and `workers/ffmpeg/` pushed to `main`. |
| **2026-07-28** | Adopted Payload 3.0 Next.js 15 App Router Architecture with Dual-Database (SQLite Dev / Postgres Prod). | Resolves ESM & React 19 compiler errors. Allows local dev with zero Postgres overhead and seamless VPS production. |
| **2026-07-29** | Adopted Headless Payload CMS 3 + `shadcn/ui` Editor Studio Architecture. | Decoupled Payload CMS 3 to act as pure headless REST API microservice; ported `shadcn/ui` Editor Studio into `web/` (`/dashboard`). |
| **2026-07-29** | Adopted Official Payload 3 Template Repository for `cms/`. | Replaced `cms/` with template from `https://github.com/alirazasilverantmarketing/payload-cms.git` to guarantee unbroken native Payload Admin UI CSS/layout while preserving custom Alamia Dark Theme web portal in `web/`. |
| **2026-07-29** | Implemented RK Media OTT Creator Studio Admin Branding & Card Backdrops. | Organized Admin sidebar into `🎬 OTT Streaming & Video`, `📰 News & Editorial`, `🏷️ Taxonomy & Governance`, `👥 Platform Access`; added custom RK Media Logo and generated background backdrops for Creator Studio dashboard cards. |
| **2026-07-30** | Adopted In-Container Payload Migration Strategy for Staging Environments (ADR-0002). | Overcomes Drizzle's inability to auto-push schemas in `NODE_ENV=production` by forcing database resets via `reset-db.js` and running `migrate:create` directly inside the Staging container, avoiding the need for a local PostgreSQL Docker setup on low-end laptops. |
| **2026-07-30** | Adopted `payload-sidebar-plugin` with `lucide-react` Hot-Patch. | Solves Payload CMS 3.x native sidebar sorting bugs ("first encounter" array sorting) while adding robust icons and custom groupings. Uses a Node.js `postinstall` script and Docker `COPY` adjustment to rewrite deprecated `Github` icon imports to circumvent breaking changes in `lucide-react` v1.0.0. |
| **2026-07-30** | Adopted HTTP-Only Cookie JWT Authentication via Server Actions. | Bypasses Payload's default local-storage JWT approach on the Next.js frontend to securely handle auth inside Next 14 Server Actions (`/actions/auth.ts`). Role updates (e.g., upgrading a guest to `subscriber`) are securely patched server-to-server. |
| **2026-07-30** | Enforced Light Mode Contrast via Native CSS Overrides. | Circumvents Tailwind's inability to parse `/80` opacity modifiers on custom hex color tokens by enforcing explicit high-contrast `!important` rules on labels and form backgrounds in `globals.css` for the `html.light` theme. |
| **2026-08-01** | Migrated News Feed to Native `Posts` Collection & Added Payload Custom Admin Components (Sprint 3). | Shifted from the legacy `Articles` collection to the template's `Posts` collection to leverage Lexical rich text and SEO meta. Built custom Payload React Client components (`ExternalVideoField`) for intelligent video embeds and live in-dashboard previews. |
| **2026-08-01** | Automated Social Feeds Background Sync & Payload Custom UI Component (ADR-0003). | Replaced manual CLI bulk import script with an automated sync solution: added a custom "Sync Feed Now" React UI Button to the `SocialFeeds` CMS sidebar requiring `generate:importmap` bundling, and injected a polling `setInterval` worker into Payload's `onInit` hook (using `context: { disableRevalidate: true }` to prevent Next.js SSR crashes). |
| **2026-08-01** | Dynamic Frontend Iframe Embed URL Parsing. | Solved YouTube's `X-Frame-Options` restriction by dynamically parsing standard `watch?v=` and `youtu.be/` links into `embed/` URLs directly inside the Next.js `iframe` rendering cycle on `/videos/[slug]`. |
| **2026-08-01** | Added Unified Admin Video Preview & News Feed Video Player. | Replaced standalone `ExternalVideoField` with a unified `VideoPreviewField` component in the CMS to preview YouTube embeds or HTML5 video tags for raw uploads. Added video fields to the `Posts` collection and updated the news detail page to display a video player when an embed URL is present. Resolved the Payload 3 drafts bug in RSS post imports by passing `draft: false`. |
